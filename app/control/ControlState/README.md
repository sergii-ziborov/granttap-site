# Authenticated control projection

`index.ts` projects public protocol payloads into bounded browser state. A
retained catalog is not a current computer heartbeat. Partial approval reports
replace only covered requests; complete reports are authoritative. Mesh
observations remain scoped to their publisher, and older observations cannot
replace newer evidence. Transcript retention is bounded and deduplicates IDs.
Successful computer control results update pause state immediately. Older
catalogs cannot undo that result, and a refused action preserves the last
confirmed state while retaining the computer's explanation.

Public entry: `index.ts`. Local tests exercise stale catalogs, approval coverage,
publisher scope, transcript pages and liveness.
