У GrantTap несколько обновляемых частей. Новая версия iPhone-приложения не обязательно меняет модуль компьютера, а свежий plugin не заменяет уже открытый MCP-процесс в coding app. Если функция появилась только с одной стороны, интерфейс может правильно ждать совместимого компонента. Начинайте проверку с того, какую часть вы обновляете.

## Четыре независимых слоя {#layers}

| Часть | Где обновляется | Что это меняет |
| --- | --- | --- |
| iPhone, iPad, Watch и Mac app | Соответствующий Apple-путь: TestFlight или App Store | Экраны, локальное поведение и поддерживаемый wire contract |
| Plugin coding app | Средствами самой coding app или её каталога | Интеграцию и объявления plugin |
| GrantTap MCP runtime компьютера | Установленный модуль и его механизм обновлений | Приём сообщений, hooks, adapters и фоновый helper |
| Собственное relay | Средствами его владельца | Транспорт, хранение зашифрованных пакетов и серверные возможности |

Обновление одного слоя не даёт права автоматически менять сторонний provider CLI, его аккаунт или все глобальные настройки. [Governance](/guide/governance) и pairing имеют собственный жизненный цикл.

## Automatic updates в карточке plugin {#toggle}

В connection card GrantTap есть **Automatic updates: On / Off**. Это сохранённая настройка runtime для данного компьютера. Выключение действует без обязательного перезапуска сервиса: оно останавливает последующие проверки и активацию автоматического обновления.

Уже начавшаяся загрузка может закончиться в отдельной staging-папке, но при Off новая версия не должна активироваться. Работающая выбранная версия продолжает выполнять свои задачи. Включение On позволяет фоновому циклу снова проверять обновления; изменение замечается на следующем минутном такте.

:::note Переключатель и marketplace
Эта настройка относится к runtime компьютера. Обновлением самого plugin из marketplace управляет coding app. И автоматизация задач GrantTap — отдельная функция: переключатель runtime не включает и не выключает расписания.
:::

Если сервис запущен с `GRANTTAP_DISABLE_AUTO_UPDATE=1`, это ограничение имеет приоритет. Карточка показывает, что настройка управляется окружением; On на другом экране его не отменяет. Менять environment следует в конфигурации своего сервиса, понимая последствия, а не случайным повторным подключением телефона.

## Когда новая версия начинает работать {#activation}

Фоновый монитор проверяет стабильный npm-релиз примерно раз в четыре часа. Сам цикл просыпается раз в минуту, поэтому «минутный такт» не означает скачивание новой версии каждую минуту. Недоступная сеть откладывает проверку и сохраняет текущую работу.

Проверенная версия устанавливается отдельно; проверяются целостность registry-пакета и совместимость Node. Для переключения своих фоновых сервисов runtime ждёт окончания текущих запросов и отсутствия pending approvals. Если новая служба не смогла стартовать, предусмотрен возврат к предыдущей версии. Staging и сохранённые версии занимают место ради rollback.

Активные provider processes и текущие stdio MCP-вызовы не принудительно заменяются. Новый launcher может выбрать проверенную версию для будущего запуска, пока уже открытая coding app ещё использует старый процесс. Это объясняет временное различие версий без необходимости сбрасывать pairing или повторять сообщение.

## Проверка после обновления {#check}

1. Убедитесь, что нужная Apple-сборка действительно доступна вашему TestFlight-аккаунту и установлена.
2. Посмотрите версию компьютера и состояние helper в карточке GrantTap либо Devices.
3. Проверьте обычную квитанцию на безопасной учебной задаче, без повторной отправки зависшего реального запроса.
4. Если coding app держит старый stdio-процесс, завершите ненужный сеанс и откройте новое подключение штатным способом этой app.
5. При несовпадении функций сверяйте обе стороны: например, меню вложений на телефоне и объявленную поддержку компьютера.

Для самостоятельной проверки установленного CLI существует `granttap status --json`. Его вывод может содержать технические сведения: перед публикацией уберите идентификаторы и приватные адреса, не добавляя ключи подключения.

## Сборка, доступность и обещания {#availability}

Загруженный архив ещё может обрабатываться Apple. Номер в сообщении разработчика не заменяет наличие сборки у вашего TestFlight. TestFlight-проверка также не означает App Review approval или появление платной покупки. Условия и доступную цену всегда смотрите в текущем StoreKit-экране Apple.

Старые скриншоты в руководстве подписаны своим build и датой. Их не перерисовывают под новые подписи. Известная смешанная RU/EN локализация Mesh здесь показана честно и не объявляется исправленной.
