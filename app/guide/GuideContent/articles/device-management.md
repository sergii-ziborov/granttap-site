Devices — рабочее место для управления подключённым компьютером. Здесь можно узнать, какой процесс GrantTap MCP действительно отвечает, проверить версии coding agents, начать вход, обновить поддержанный инструмент и посмотреть объём удаляемого кэша. Эти действия относятся к выбранному компьютеру, а не ко всем устройствам аккаунта.

## Открыть нужный компьютер {#open}

1. Откройте вкладку **Devices**.
2. Найдите компьютер по имени. Если компьютеров несколько, сверьте, на каком выполняется нужная Task.
3. Откройте его управление. В начале находятся GrantTap MCP и действия подключения, ниже — кэш и Coding agents.
4. Нажмите **Refresh status**. Дождитесь ответа выбранного компьютера.

## Различать запущенную и установленную версии {#versions}

Основная строка GrantTap MCP показывает **работающий процесс**. Строка **installed · restart to activate** означает, что другая версия уже установлена или выбрана, но ещё не обслуживает это соединение. Это нормальные разные состояния, а не две копии одной успешной операции.

| Что видно | Что делать |
|---|---|
| Текущая версия и Check for MCP update | Проверить доступность обновления |
| Update MCP to … | Начать обновление выбранного компьютера |
| Новая версия installed, старая продолжает отвечать | Подготовиться к перезапуску, затем дождаться новой квитанции |
| MCP restart confirmed | Перезапуск подтверждён компьютером |
| This computer did not answer | Проверить питание, сеть и модуль на этом компьютере |

:::capture mcp-updated

Числа версий на учебном снимке — значения фикстуры, а не рекомендуемая версия для установки. Актуальность руководства и проверенные исходники перечислены в [покрытии](/guide/coverage).

## Обновить GrantTap MCP {#update-mcp}

Нажмите **Check for MCP update** или предложенное обновление. Не отправляйте повторную операцию, пока первая выполняется. После результата перечитайте обе версии. Если новая только установлена, нажмите **Restart MCP**, прочитайте подтверждение и продолжите. Связь временно переподключится. Завершение окна на телефоне само по себе не подтверждает новый процесс.

Автообновление MCP и обновление приложения через App Store/TestFlight независимы. В карточке видно состояние Automatic updates; доступные настройки зависят от версии модуля. Исходная developer-установка из checkout может требовать ручной сборки. Подробный порядок — в [обновлениях](/guide/updates).

## Обновить Claude, Codex, Grok или Cursor {#update-provider}

В блоке **Coding agents** найдите провайдера. Проверьте версию и состояние входа, затем нажмите **Update** и подтвердите обновление. Модуль использует поддержанный установщик конкретного инструмента на этом компьютере. При установке через неподдержанный способ результат объяснит, что нужно сделать в доверенном терминале.

Изменение одной карточки не обновляет остальные инструменты. Версия встроенной копии CLI в desktop-приложении может отличаться от отдельной установки. Результат «версия не изменилась» следует прочитать: инструмент может быть уже актуален либо обновление не состоялось. Не подменяйте его выводом «кнопка нажата».

## Перезапуск и активная работа {#restart}

**Restart** у провайдера относится к CLI-процессам, запущенным GrantTap для него. Подтверждение предупреждает, что активный запрос может остановиться. Сохранённые чаты остаются, отдельные desktop-сессии не перезапускаются этим действием. **Restart MCP** переподключает модуль GrantTap; это другая кнопка и другая область действия.

Сначала закончите или осознанно остановите текущий запрос. Для обычного повторного чтения состояния используйте Refresh status. Перезапуск не исправляет неверный логин и не является повторной отправкой зависшего сообщения.

## Проверить результат {#verify}

После изменения дождитесь ответа и обновите состояние. Сверьте имя компьютера, реально запущенную версию и конкретного провайдера. При ошибке сохраните её текст без токенов. Если нужна авторизация, откройте [вход в провайдера](/guide/provider-sign-in); если не хватает места — [кэш и хранение](/guide/cache-storage).
