## Что получится после первого подключения {#result}

GrantTap позволяет увидеть на телефоне работу coding agents с ваших компьютеров, ответить на вопрос, согласовать действие и продолжить нужную задачу. Сам код исполняется на выбранном компьютере, а модели и их аккаунты остаются у coding provider.

Для первого знакомства не нужно сразу настраивать весь Mesh. Удобный порядок: посмотреть встроенное Демо, подключить один компьютер, найти один безопасный разговор, отправить учебное сообщение и проверить его этапы. Затем можно переходить к правилам проекта, переносу задач и остальным возможностям.

Скриншоты iPhone в этом руководстве сняты с настоящего интерфейса GrantTap в Simulator на встроенных учебных данных. Это не доказательство выполненных на реальном компьютере команд. Отдельный репозиторий **GrantTap Lab** ниже предлагается для вашей собственной практики.

## Шаг 1. Осмотреться без подключения {#demo}

На экране начала или подключения выберите **Explore demo / Демо**, если этот вариант предложен. Здесь не нужны passkey, покупка, MCP и работающий компьютер. Откройте Now, найдите учебный вопрос и посмотрите Task.

Обратите внимание на провайдера и компьютер рядом с названием. Task — сама работа, execution — конкретный сеанс её выполнения. Внутри чата есть поле сообщения, Files, Agents и поддерживаемые controls. Демонстрационный ответ меняет только учебное состояние; настоящий prompt или command не запускается.

Для выхода откройте Settings → **Exit Demo**. Вернётся обычное подключение. Не используйте demo status как проверку live связи: подробности режима находятся в [учебном проекте](/guide/demo-project).

## Шаг 2. Подготовить компьютер {#computer}

На компьютере, где работают агенты, нужен отдельно установленный helper `granttap-mcp`. В своём терминале выполните:

```bash
npm install --global granttap-mcp
granttap setup
granttap status
```

Нужен поддерживаемый Node.js, минимум **22.13.0**. Setup устанавливает или чинит собственные интеграции GrantTap и фоновые службы; status читает готовность. Сторонний coding provider должен быть уже установлен и авторизован вами.

Установите plugin для используемой coding app по [инструкции установки](/guide/installation). Claude Code и Codex — основные интеграции. У Cursor и Grok есть свои границы; одинаковая карточка Task не означает одинаковый контроль всех инструментов.

## Шаг 3. Связать телефон {#connect}

Выберите один удобный способ. Для личной сети устройств откройте Devices в GrantTap, войдите с passkey и используйте тот же аккаунт в connection card MCP на компьютере. Аккаунт может существовать ещё до подключения первого Mac.

Для прямого подключения откройте GrantTap connection card в coding app, выберите **Add a device** и отсканируйте одноразовый QR через Devices → Add a device → Scan QR на телефоне. Не вставляйте действующий QR в чат и не делайте его публичным.

Авторизация MCP внутри coding app — отдельный шаг. Сохранённая пара телефона не означает, что новый coding client уже одобрен. Различия passkey, computer QR, account QR и Project invite объясняет [подключение устройств](/guide/pairing).

## Шаг 4. Найти правильную Task {#task}

Проверьте Devices: нужный компьютер должен быть доступен. Затем откройте Now или Tasks и выберите безопасный учебный разговор. Сверьте три вещи: название проекта, provider и computer.

Если Task переносилась, определите current execution. Старый Claude-чат и новое Grok-исполнение могут относиться к одной работе, но быть разными native conversations. Не продолжайте историческую ветку случайно; [handoff](/guide/handoff) объясняет banner Transferred и Open destination.

Неустановленный provider не является ошибкой. Live у соединения показывает доступность маршрута, а не успешное выполнение каждой карточки. Если в каталоге пока нет ожидаемой работы, начните с [диагностики](/guide/troubleshooting#connection), а не удаления всех pairings.

## Шаг 5. Отправить и проверить {#message}

В своей реальной учебной Task попросите объяснить небольшой README без изменения файлов. После принятой отправки клавиатура сворачивается. Нажмите статус исходного сообщения и прочитайте подтверждённые этапы.

| Этап | Что уже известно |
| --- | --- |
| Saved on relay | Зашифрованная операция сохранена на реле |
| Received by computer | Компьютер подтвердил получение |
| Agent activity received | Получена соответствующая агентная активность |

Не ожидайте, что открытое окно провайдера, список Tasks и все receipts обновятся в один момент. Около тридцати секунд на отдельное обновление каталога не является измеренным средним доставки. Полный разбор — [как доставляется сообщение](/guide/message-delivery).

:::warning Не проверяйте связь повторным «Го»
Если статус непонятен, обновите исходную запись. Агент мог получить сообщение до того, как обновился экран. [Cancel и Delete](/guide/message-queue) имеют разные последствия и не заменяют проверку истории.
:::
