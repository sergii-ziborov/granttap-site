В рабочей папке чата часто лежат изменения, которые агент ещё не закоммитил. GrantTap показывает их числом, открывает список файлов, позволяет закоммитить ровно эти файлы с телефона и показывает все worktree репозитория — ведь агенты нередко работают в отдельных worktree рядом с папкой чата.

:::capture changes-worktrees

## Где увидеть незакоммиченное {#pill}

Если в папке чата есть изменения, справа в строке под заголовком чата стоит янтарная пометка с веткой, например **9 изменений**. Та же пометка есть в конце строки состояния карточки чата в **Сейчас** и **Задачах**, когда на ней хватает места; при самых крупных размерах текста карточка её не показывает. Тап по пометке в чате открывает лист **Изменения**.

Пометка появляется, только если компьютер сообщил о папке внутри Git-репозитория и изменений больше нуля. Для неё нужен GrantTap MCP 0.8.190 или новее.

## Что в листе «Изменения» {#sheet}

Вверху — ветка и папка чата (`~/…`), справа расстояние до upstream: `↑2` — два коммита впереди, `↓1` — один позади. Если репозиторий без ветки (detached) или в нём идёт merge или rebase, лист предупреждает об этом.

Ниже — список файлов, у каждого одна цветная буква Git:

| Буква | Значение |
|---|---|
| **M** | Изменён |
| **A** | Добавлен |
| **?** | Не отслеживается |
| **D** | Удалён |
| **R** | Переименован, рядом старый путь |
| **U** | Конфликт |

Больше восьми файлов группируются по папкам. Если компьютер прислал не весь список, лист пишет, сколько показано.

## Worktree репозитория {#worktrees}

Под веткой лист перечисляет worktree репозитория чата: **Worktree: 3 · веток: 3**. У каждого — имя папки и ветка или **Без ветки, на c4a7f19**, замок, если Git его заблокировал, пометка **Этот чат** у собственной папки чата и галочка у той, что сейчас показана. Видно первые пять, остальные открывает **Показать все: N**.

Нажмите другой worktree, чтобы посмотреть его изменения. Он открывается только для просмотра: **Другой worktree, только просмотр. Коммит делается в папке этого чата.** — и без кнопки коммита. Тап по собственной папке чата снова показывает её с **Закоммитить**.

Список worktree требует GrantTap MCP 0.8.202 или новее. Телефон спрашивает про конкретный worktree, только если компьютер сам назвал их в списке: более старый компьютер такой запрос отклонил бы и не ответил.

## Закоммитить с телефона {#commit}

1. Проверьте ветку и список файлов: коммит возьмёт ровно показанные пути.
2. В поле **Сообщение коммита** уже стоит название чата (первая строка, до 72 символов). Исправьте его при необходимости.
3. Нажмите **Закоммитить**. Если ход этого чата ещё идёт, приложение сначала спросит подтверждение.
4. Успех выглядит как **Закоммичено: 3f9c2a1**, после чего список читается заново.

Коммит делается на этом компьютере и **ничего не отправляет в remote**: push остаётся вашим или агента решением. Коммит привязан к снимку списка. Если папка изменилась с момента чтения, компьютер откажет, и лист покажет новый список. Поэтому повторный коммит по старому списку не закоммитит ничего дважды.

:::warning Сначала проверьте, что коммитите
Коммит с телефона удобен для фиксации готовой работы, но не заменяет просмотр diff. Откройте файлы в [Files](/guide/transcript-sources#files) или попросите агента показать diff, если не уверены в содержимом. Отказ компьютера (detached, merge, работа агента) объясняется в листе обычными словами.
:::

## Если компьютер молчит {#retry}

Телефон ждёт ответа десять секунд. Затем лист пишет **Компьютер не ответил.** и предлагает **Повторить** — новый запрос, не повтор старого. Если папка чата не является Git-репозиторием, который компьютер может прочитать, лист спокойно сообщает об этом без предупреждающего цвета и предлагает **Проверить снова**. Коммит, который компьютер не подтвердил вовремя, отмечается отдельно, и список читается заново.

:::note Изменения агентов в Files
Лист «Изменения» показывает состояние Git в папке. **Files** показывает, что записали ответы чата и запущенные им агенты, по каждой рабочей копии отдельно. Это разные источники, см. [Files и Agents](/guide/transcript-sources#files).
:::

:::exercise Учебный репозиторий
В демо найдите в **Сейчас** чат «Write three blog posts…» с пометкой **9 изменений**. Откройте чат и нажмите пометку. Найдите worktree с замком, откройте `applydjin-hero-images` только для просмотра и вернитесь к папке **Этот чат**. Не нажимайте **Закоммитить**: в демо коммит не уходит на компьютер, но привычка проверять список полезна.
:::
