# JSONTestSuite fixtures

`test_parsing/` is the parsing corpus from
[nst/JSONTestSuite](https://github.com/nst/JSONTestSuite), dedicated to the
public domain. Only that directory is vendored.

Policy used by this crate:

- `y_*` must parse as a complete `Value`
- `n_*` must be rejected
- `i_*` are implementation-defined; the locked lists in
  `tests/json_test_suite.rs` record this crate's choices. In short: reject
  invalid UTF-8, lone/incomplete surrogates, a UTF-8 BOM, nesting deeper than
  the default depth limit, and numbers that are not a finite JSON number.

`lexical-write-float/src/compact.rs` is a direct port of a C++ implementation of the Grisu algorithm, found [here](https://github.com/night-shift/fpconv/).
This code (used if both the `write-floats` and `compact` features are enabled) is subject to a [MIT License](https://github.com/night-shift/fpconv/blob/dfeb7e938fb85fb5eca130b84f856705ced75012/license), shown in the [fpconv License](#fpconv-license) section below.
