# GrantTap Lab

Небольшой учебный проект для практики с GrantTap. Здесь нет сети, аккаунтов,
ключей, платёжных сервисов, зависимости от AI API или сторонних npm-пакетов.
Суммы выражены в целых копейках. Это учебная модель расчёта корзины, не готовый
платёжный модуль.

## Проверка

Требуется Node.js 22+. Устанавливать зависимости не нужно:

```bash
npm test
```

Исходный результат: 6 тестов, 6 успешно.

## Практика

1. Поместите папку в отдельное рабочее место. При желании создайте Git-репозиторий
   и исходный commit обычным способом. Не используйте рабочий продукт с секретами.
2. Откройте эту папку в поддерживаемом coding app, подключённом к GrantTap.
3. Попросите своего агента добавить промокод `HELLO10`: 10% только на товары,
   без скидки на доставку. Сначала добавьте новые тесты, затем реализацию.
4. В GrantTap проверьте компьютер, Task, состояние доставки и полученный ответ.
5. Сравните Files, локальный diff и настоящий вывод `npm test`.
6. Если хотите испытать Governance, используйте отдельный учебный Project Mesh.
   Разрешение на установку учебного примера не меняет ваши глобальные правила.

Ни один из приведённых шагов сам не запускает AI-агента. Действия и отправки
делает пользователь. Скриншоты руководства сняты на встроенном учебном наборе
GrantTap; это не доказательство исполнения задания в этой папке.

Полный практикум: https://granttap.com/guide/walkthrough
